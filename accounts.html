Adding and managing accounts

RuneScape now requires a Jagex Account. You sign in once through the launcher, it fetches your characters for you, and from then on launching one is a single click.

Add your first account

  1. Open Accounts

    It is the first item in the sidebar. On a fresh install you will see Add your first account.

  2. Click Add Jagex account

    You will find it on the ADD AN ACCOUNT card.

  3. Sign in and accept the consent screen

    The launcher opens the Jagex sign-in for you. Complete it exactly as you would on the Jagex website, including any verification code.

  4. Your characters arrive on their own

    When it succeeds the launcher tells you how many characters it found — “Added 3 Jagex character(s). Pick one and continue.” You never type a character name in by hand.

Repeat for as many accounts as you like. Each one becomes its own card under JAGEX ACCOUNTS.

Launch a character

  1. Click the account card to expand it

    The card shows how many characters it holds. Clicking it (or the chevron on the right) opens the list. With more than one account you also get Expand all / Collapse all.

  2. Press Launch next to the character you want

    The launcher does the rest. Progress is reported as it goes, and the session then appears under Monitor.

The framework is separate

Launching a character starts the game. Your scripting framework is started from Script Hub, and the two are independent — you can start them in either order. See Scripting framework →

Rename and remove

Each account card carries two buttons.

ButtonWhat it does
Rename Sets a nickname so you can tell accounts apart at a glance. It is a label in the launcher only — nothing about the account itself changes. Clear the box to go back to the Jagex name.
Remove Deletes the launcher’s saved session and character list for that account. Your game progress is not affected, and you can add the account back at any time by signing in again.
A new account shows no characters yet

A freshly added Steam-edition account says “Characters populate after the first launch.” That is expected — the list fills in once the game has been through the lobby once.

Optional: fill in the emailed code automatically

Jagex emails a six-digit verification code when you sign in. The launcher can type that code in for you instead of you fetching it from your inbox. The toggle is Fill in the emailed code for me, on the ADD AN ACCOUNT card.

It is off by default. With it off, signing in behaves exactly as it always has.

It needs a desktop mail client

This works by a rule in a mail program running on this PC — Thunderbird, or the classic Outlook desktop app — handing the code to the launcher locally.

If you only use webmail (Gmail or Outlook.com in a browser, with nothing installed) there is no hands-free option. Leave the toggle off and type the code in, which works exactly as it always did.

To set the rule up, run this and follow what it prints:

# in %LOCALAPPDATA%\Programs\BotWithUs\Launcher
.\bwu_cli.exe jagex mail-setup

It prints the current instructions for your mail client. Run it again whenever you need them — it is the up-to-date source, so nothing here can go stale on you. More on the command line →

The launcher never holds your email password

There is no mail client inside the launcher, no stored app password, and no sign-in to your email provider. It only accepts a code handed to it by something already running on your own machine.

Watching your sessions

Monitor lists the sessions you launched from this launcher.

  • Each row shows the character, how long it has been up, and its process id.
  • Stop ends that session.
  • The Auto-restart toggle decides what happens if a session exits on its own — on, the launcher brings it back; off, it stays closed.

Nothing here yet? You will see “No attached sessions. Launch a client from the Accounts tab.”

Steam-linked accounts

Steam-edition accounts appear in their own STEAM ACCOUNTS section and behave the same way once added. Setting one up is not covered by this guide yet — ask in support and we will walk you through it.
