Getting started

Get started with the launcher

The BotWithUs Launcher is the one app you open: it signs you in, keeps your accounts, starts RuneScape, and starts your scripting framework. This guide takes you from a fresh install to a running script.

1. Install it

  1. Download the installer

    Grab BotWithUs.msi from botwithus.com/download and run it.

  2. Let it install for your user account

    It installs to %LOCALAPPDATA%\Programs\BotWithUs\Launcher and adds a BotWithUs Launcher shortcut to your Start menu.

  3. Open it from the Start menu

    The shortcut should open the launcher straight away.

You should never be asked for an administrator password

The installer is per-user and needs no elevation. If a User Account Control prompt appears, stop and tell us — that points at a problem with the package, not with your PC.

If Windows SmartScreen warns you

Click More info → Run anyway. If your browser deletes the download outright instead of warning you, let us know — that is worth hearing about.

2. Sign in

The first thing the launcher shows is a sign-in screen.

  1. Click Sign in with Discord

    Your browser opens. Finish signing in there, then switch back to the launcher — it picks up the result on its own.

  2. Wait out the first-run download

    On its first run the launcher fetches the pieces it needs and keeps them up to date afterwards. Let the progress finish before you launch anything.

Already have a token from the website? Use a saved token signs you in with that instead.

3. Find your way around

Everything lives in the left sidebar:

Know your version number

The launcher prints its version in the bottom corner. Quote that number whenever you ask for help — it is the fastest way for anyone to tell what you are running.

Keeping it up to date

When a newer build is published, a Launcher update notice appears at the top of the launcher.

  • Download fetches the new BotWithUs.msi in your browser. Run it the same way you ran the first one — there is no need to uninstall anything first.
  • Not now hides the notice until you next open the launcher.

The pieces the launcher downloads for itself are separate, and update themselves each time it starts.
