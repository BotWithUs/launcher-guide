Scripting

Opening the scripting framework

The scripting framework is the window where your scripts actually live. The launcher starts it for you — on a fresh install there is nothing to configure.

Two places, one job

You launch frameworks from Script Hub.
You configure them in Preferences.
If you are hunting for the Add framework button, it is in Preferences.

Start the framework

  1. Open Script Hub

    It sits under SCRIPTING in the sidebar.

  2. Find BotWithUs (Java) under YOUR FRAMEWORKS

    This entry is already set up on a new install. Nothing to point at, nothing to fill in.

  3. Press Launch

    The framework opens in its own window. Give it a moment on first start.

You can launch the game from Accounts before or after this — the framework and the game client are independent, and the framework finds your running clients on its own.

The launcher does not babysit it

The launcher starts the framework and then lets it be. Closing the launcher does not close the framework, and the framework does not appear under Monitor — that list is for game sessions.

What a framework row tells you

Every row in Script Hub shows three things:

PartMeaning
The nameWhatever it was called when it was added.
JAVA / EXE chip How it starts — a Java runtime, or a plain executable.
The grey line A preview of the exact command that will run, so you can see at a glance what Launch is about to do.

Getting scripts to run

Scripts come from the Script Market. From Script Hub, press Open the Script Market — it opens botwithus.com/sdn in your browser. Anything you have access to there is available inside the framework once it is running.

If the list is empty

If you have removed every framework, Script Hub shows Add your first framework instead of a list.

  • Press Set up a framework — it takes you to Preferences with the editor already open.
  • To get the original BotWithUs (Java) entry back instead, see Start over on the next page.

Running your own framework

You are not limited to the bundled one. Any executable, or any Java program, can be added as a framework and launched from here — useful if you are writing your own. That is covered in detail on the next page.
